# 三轴平台式惯导数字样机（导航—稳定闭环版）

## 1. 坐标与框架约定

- 导航坐标系：东北天（ENU）。
- 三层框架严格采用：载体 → 外环 X → 内环 Y → 台体 Z。
- 各轴正方向按右手定则。
- 框架变换：`C_p^b = Rx(x) Ry(y) Rz(z)`。
- 载体姿态：`C_b^n = C_p^n (C_p^b)^T`。
- 游移角按微分方程更新，导航结果最终转换并输出到东北天。
- 导航层100 Hz、稳定回路2000 Hz，通过协同迭代实现双速率闭环。

## 2. 文件

- `par.m`：全部参数，含笔记参数和暂定参数。
- `make.m`：自动生成三轴 Simulink 稳定回路 `model.slx`。
- `model.slx`：外环 X、内环 Y、台体 Z 三轴稳定回路。
- `nav.m`：东北天游移方位平台机械编排。
- `run.m`：生成输入、运行 Simulink、生成传感器脉冲、导航解算和绘图。
- `result/data_ideal.mat`：关闭测量误差后的闭合验证结果。
- `result/data.mat`：启用暂定误差后的工程结果。

## 4. 已纳入模型

- 三轴不同转动惯量、力矩系数和电机时间常数。
- 三轴同一套校正网络，独立 PID 参数入口。
- 三轴均具有导航轴速率指令输入，控制量采用“测量轴速率−指令轴速率”。
- 地球自转、运输角速度和游移角速度在导航层统一计算。
- 导航角速度经X-Y-Z速率分配矩阵转换为三个框架轴指令。
- FOG 一阶动态、标度因数、安装误差、零偏、随机游走、温漂和饱和。
- 加速度计零偏、标度因数、安装误差、随机游走、温漂和饱和。
- 编码器零偏、量化、框架轴不正交的一阶等效误差。
- 杆臂误差、振动整流误差。
- 电流、力矩和限流状态输出。
- 经纬高、ENU 速度、横滚/俯仰/航向、游移角和框架状态输出。

## 5. 当前结果

- 理想闭合 60 s：位置回到初值，末速度约 `1e-11 m/s`，说明造数与机械编排闭合。
- 含暂定误差 60 s：末 ENU 速度约 `[-0.0037, 0.0099, 0.1423] m/s`；高度误差约 `4.31 m`。
- 三轴峰值角速度约 `[0.195, 0.181, 0.254] deg/s`。
- 三轴峰值电流约 `[0.154, 0.187, 0.226] A`，本工况未触发限流。
- 含误差工况末游移角约 `-0.00368 arcsec`。
- 台体Z轴导航指令峰值约 `3.50e-8 deg/s`；静基座下数值很小属于正常结果。

## 6. 下一阶段

当前版本已经闭合导航层和稳定回路。以下物理细节仍应在获得结构或试验数据后继续细化：

- 三框架完整耦合刚体动力学，而非三个独立等效转轴。
- 轴不正交对力矩和角速度传递的非线性耦合。
- 质量不平衡、线缆力矩、库仑摩擦、间隙的实测模型。
- 电机电气方程中的电阻、电感、反电势和母线电压限制。
- FOG/加速度计 Allan 方差辨识后的随机过程参数。
- 外部实测脉冲数据、框架角和电机电流的文件接口。
